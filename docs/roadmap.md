# Roadmap

## Prepared locally

The bootstrap supplies the dated research snapshots, 12 structured resource records, supporting tables, 30 primary references, ten seed references, generated pages, contribution rules and local checks. It is not yet a published repository change or a tested training range.

## Next acceptance gates

| Priority | Work item | Acceptance evidence |
| --- | --- | --- |
| 1 | Reconcile and publish the metadata baseline | Accessible repository; reviewed diff; owner-approved license decision; actual commit and pull-request references |
| 2 | Freeze exact upstream revisions and permissions | Per-resource source/version records; permissible access model; unresolved terms kept visible |
| 3 | Audit the first permitted capture excerpts | File manifest, hash, protocol dissection, capture vantage, clock checks, privacy review and answer key |
| 4 | Build one instrumented synthetic plant | Separate simulator state, controller readings, operator events and synchronized packet capture |
| 5 | Publish the first exercises | Tested participant instructions, scoring rubric, reproducible expected results and facilitator review |

## Proposed first portfolio

Use the inherited [build plan](reference/build-plan.md) for initial selection. Candidate directions are contextual packet analysis, heterogeneous asset discovery, and one process-backed synthetic incident. These remain proposals until their technical and rights gates pass.

All [twelve existing gaps](reference/gap-register.md) remain open; packaging the catalog does not close them. Safety-system material and the broader awareness curriculum remain discovery work through the original seed sources.
